# 에테리아 — 판타지 환생 시뮬레이터

React + TypeScript로 만든 브라우저 로컬 게임입니다. LLM API나 게임 서버는 사용하지 않습니다.

## 실행과 검증
- `npm install`
- `npm run build`: TypeScript 검사 및 Vite 정적 빌드
- `npm test`: 출생 10,000회, 6종족 144회 완주, 95개 이벤트의 모든 선택지 도달성, 저장·판정 재현 검증

## 구성
- `src/data/world.ts`: 6종족 / 6국가 / 15직업 / 출생 가중치
- `src/data/events.ts`: 95개 조건부 이벤트와 실제 효과
- `src/engine.ts`: 시드 난수, 조건 판정, 활동, 세계 연간 갱신, 노화, 인연, 엔딩
- `src/storage.ts`: 버전 1 로컬 저장과 최대 30개 인생 보관
- `src/main.tsx`: React 화면 및 사용자 동작
- `src/style.css`: 반응형 책장·양피지 UI

## 규칙과 범위
- 모든 새로운 삶은 세계력 500년에서 시작하며 세계는 초기화됩니다.
- 실제 나이 / 종족 평균수명 비율로 유년기 0~15%, 청소년기 15~25%, 성인기 25~75%, 노년기 75% 이상을 구분합니다.
- 턴은 1~5년, 노년기는 1~3년입니다. 세계와 NPC는 매년 갱신합니다.
- 출생 신분 4는 각 국가의 최상위 가문 그룹이며 왕족만을 뜻하지 않습니다. 노르딘에는 왕족이 없습니다.
- 마족의 마법 소비 감소는 마법 활동·선택의 스트레스 비용에 적용됩니다. 별도 MP 자원은 없습니다.
- 국가는 지표·통치자·관계를 갱신하며 전쟁/흉년/역병/성장/침체/반란/정치 변화/마법 발전 사건이 있습니다. 전체 경제·주민 시뮬레이션은 아닙니다.
- 가족 맞이는 출산 또는 입양으로 추상화되며 NPC의 일별 행동은 시뮬레이션하지 않습니다.
- 신분과 학력은 독립 상태입니다. 판정에는 실제 능력치, 종족 보정, 조건, 시드가 사용됩니다.
- 수명은 강제 종료점이 아닌 종족별 연간 사망 확률의 기준입니다.
- 로컬 자동 저장 및 종료 기록 보관. JSON 내보내기는 보관용이며 가져오기·클라우드 저장·연속 세계는 미지원입니다.
- 이 환경에서는 제어 가능한 브라우저가 제공되지 않아 브라우저 시각 QA는 수행하지 않았습니다.

## v1.3 모험·몬스터·희귀 보스
- 여행 메뉴의 모험 시작으로 8 G + 생활비를 지불하고 현재 국가를 탐험합니다. 청소년기 이후, 건강 30 이상에서 가능합니다.
- 슬라임, 고블린, 마수 늑대, 요정, 유적, 골렘, 미믹, 망령, 와이번, 수정 동굴, 탐험대 구조, 희귀 고룡까지 12개 사건을 추가했습니다. 총 107개 이벤트입니다.
- 전투력은 max(체력×.6+민첩×.25+정신력×.15, 마력×.6+지능×.25+정신력×.15) × (.6+건강×.004), 룬 검 +6 / 요정 축복 +3, 최대100입니다.
- 고룡은 성인/노년기의 생존 활동 완료 시 0.3% 독립 판정으로 등장하며 인생당 1회입니다. 일반 가중치 추첨에서는 제외합니다.
- 고룡 도전: 전투력75·건강50 이상. 성공률 clamp(50+전투력−80,5,95). 승리 재산+700·명성+60·건강−25, 실패 사망. 종족 전투 피해 보정과 기존 재산 자동 상환·명성 상한은 유지됩니다.
- 전투와 별개로 비전투 대피 선택이 있습니다. 일부 피해를 받는 선택은 현재 건강에 따라 일반 건강 사망 규칙이 적용됩니다.
- `node --import tsx src/adventure.test.ts`: 등장빈도1만회, 강약·마법빌드·건강 조건, 승패·사망·보상·전리품·엔딩, 재접속 판정 고정, 재등장 제한, 모험 선택 검증.

## 턴제 모험 업데이트
- 일반/위험/전설 모험 선택. 7개 신규 사건, 기존 몬스터 포함 15종 전투.
- 공격/마법/방어/회복약/도주, 3턴마다 강타 예고. 실제 건강을 사용하며 0이면 사망. 전투 행동은 나이/연도를 증가시키지 않음.
- 회복약 일반 2개, 전설 3개. 마족 마법 자원 소모 5(기본 6), 용인 피해 10% 경감.
- 미궁 3연전과 폐탑 2연전은 건강/회복약 유지, 방 사이 마력 6 회복.
- 전설 최초 승리: 업적 영구 저장(해당 인생) + 작위/사회적 지위 한 단계 상승 또는 히든 직업 선택. 최고 신분은 대신 200 G. 반복 승리는 일반 전리품만 지급.
- 히든 직업 용사/고대 수호자/미궁 정복자는 실제 직업·수입·작업 위험도를 사용. 일반 직업 선택창에서는 해금 전 진입 불가.
- 전투 상태와 보상 선택은 기존 localStorage 게임 저장에 포함. 기존 세이브의 새 필드는 선택적이므로 이전 기록을 초기화하지 않음.
- 도트풍 캐릭터/몬스터는 로컬 SVG 픽셀 그림. 외부 이미지 서비스 없음.
- 검증: engine.test.ts, battle.test.ts, adventure.test.ts, reputation.test.ts, update.test.ts. 브라우저 도구 부재로 실제 브라우저 시각 검증은 수행하지 않음.


## 가족과 관계 업데이트
- 대화/선물: 전체 NPC를 통틀어 행동별 활동 턴당 1회. act(person) 호출도 무료 행동으로 연결하며 나이/연도/턴/난수를 소모하지 않음. 사용 기록 저장. 선물 10 G.
- 성년 연인 호감도70 이상 결혼, 20 G. 배우자 생활비 연3 G 추가, 배우자 직업/경제 기반 수입은 모든 활동에서 가계에 합산.
- 빚20 G 이상 3턴 또는 대화 없음3턴부터 각각 호감도 -5, 이후턴마다2씩 악화(각 최대12). 선물은 대화 공백 초기화하지 않음. 호감도50 미만 경고,30 미만 이혼확률 clamp((30-호감도)*2,5,60)%.
- 출산 준비금15 G, 임신은 활동1턴. 여성 측 연수입/연금만 해당 활동 전체 기간 중단. 활동 종료의 다음 턴 경계에 출산(신생아0세), 이후 수입복귀. 여성 배우자 사망 시 임신 종료. 이혼 이후에도 살아 있는 임산부의 출산/양육은 이어짐.
- 독립 전 자녀마다 생활비 연2 G(성년도 독립 전까지 포함). 성년 도달 턴0부터 독립확률 min(100,30+3*경과턴). 기록과 관계는 독립 후 유지.
- 기존 저장의 성별은 난수 소모 없이 보완. 기존에 이미 성년 직업을 갖고 독립한 자녀는 독립 상태로 보존. 부부 갈등 카운터는 업데이트 시점부터 집계.
- 검증: family.test.ts, update.test.ts, engine.test.ts.
