# 에테리아 — 판타지 환생 시뮬레이터

무작위로 태어난 한 인물의 출생부터 죽음까지 살아가는 한국어 웹 기반 판타지 인생 시뮬레이션 게임입니다. 영웅뿐 아니라 농부·상인·장인으로 보내는 평범한 삶도 하나의 완전한 결말입니다.

[게임 플레이](https://aetheria-lifebook.sunlitkrill16.chatgpt.site)

## 주요 기능

- 가중치 기반 무작위 출생: 종족, 성별, 국가, 가정, 신분, 이름, 능력치
- 인간·엘프·드워프·수인·마족·용인 6종족, 6개 국가와 고정 세계관
- 종족별 이름, 가족 성 일치, 인물 이름 중복 방지, 남녀 대표 초상 12종
- 기본 직업 15종과 히든 직업 3종, 직업 변경과 경력 연속 사건
- 선천적 재능 1~5단계에 따른 능력치 성장 차이
- 총 246개 이벤트. 이 중 행동 전용 사건 111개, 18직업별 업무 사건 각 5개
- 공부·훈련·일하기·휴식·교류·여행: 관련 사건 선택 → 실제 변화량 결과 모달 → 50% 확률의 추가 사건
- 시험·계산 문제·룬 독해, 마법·체력·정신 훈련과 모의 대련
- 3단계 모험, 15종 전투 조우, 공격·마법·방어·회복·도주 및 다층 미궁
- 희귀 드래곤, 전설 도전 업적, 작위 상승 또는 히든 직업 보상
- 명성 기반 작위 하사·상위 직업 스카우트
- NPC 교류, 턴을 소모하지 않는 대화·선물(각 턴당 한 번), 결혼·배우자 소득·임신·출산·자녀 독립·이혼
- 연간 생활비·소득·부채·상환, 국가 지표 변화와 세계 사건
- 종족별 노화·사망, 생애 평가·묘비명·연대기, 엔딩 이미지 저장 및 지원 기기의 공유 기능
- 브라우저 자동 저장, 인생 기록 보관, 다크 모드, 큰 글씨 모드, 모바일 대응

## 기술 구성

React 19 · TypeScript · Vite 6 · CSS · Lucide React. 게임 규칙과 콘텐츠 데이터는 UI에서 분리되어 있습니다. 게임 플레이에 외부 LLM API나 백엔드 서버는 필요하지 않습니다.

## 로컬 실행

Node.js 22 이상을 권장합니다.

```bash
npm ci
npx vite --host 0.0.0.0
```

터미널에 표시되는 주소로 접속합니다. 프로젝트에는 별도 `dev` 스크립트가 없으므로 Vite를 직접 실행합니다.

```bash
npm run build
npx vite preview --host 0.0.0.0
```

`npm run build`는 TypeScript 검사 후 `dist/`에 정적 사이트를 생성합니다. 정적 호스팅 서비스에 `dist/`를 게시할 수 있습니다. 프로젝트가 도메인 루트 경로에 배포되는 것을 기준으로 하며, 하위 경로 배포 시 Vite base와 절대 경로 이미지 참조를 함께 조정해야 합니다.

## 검증

```bash
npm test
node --import tsx src/activityFlow.test.ts
node --import tsx src/battle.test.ts
node --import tsx src/family.test.ts
node --import tsx src/talents.test.ts
node --import tsx src/reputation.test.ts
node --import tsx src/update.test.ts
```

`npm test`는 출생 가중치, 이벤트 선택지 도달성, 6종족 144회 생애 완주, 상태 범위와 저장 재현성을 검사합니다. 별도 테스트 파일은 활동 순서·전투·가족·재능·명성·이전 저장 호환성을 검증합니다. 브라우저의 실제 시각 QA와 모든 모바일 기기에서의 동작을 보증하는 테스트는 아닙니다.

## 데이터와 저장 방식

종족 수명을 기준으로 생애 단계를 계산하며, 활동 하나는 단계에 따라 여러 해를 진행합니다. 수명은 확정 사망 나이가 아니라 노화·사망 확률의 기준입니다. 시드 난수 상태와 진행 중 사건·전투·보상도 저장하여 새로고침 후 이어갈 수 있습니다.

저장은 브라우저 `localStorage`에 이루어집니다. 사용자 계정·서버 저장·기기 간 동기화·JSON 불러오기는 구현되어 있지 않습니다. 브라우저 데이터를 지우면 진행 기록이 사라질 수 있습니다. 이 저장소의 게임 데이터는 콘텐츠 정의이며 실제 플레이어의 개인 저장 파일을 포함하지 않습니다.

## 외부 리소스와 운영 설정

- 초상은 AI 생성 대표 이미지로, 캐릭터의 실제 연령·직업을 모두 표현하지 않습니다.
- `index.html`에는 기존 운영 사이트의 Google AdSense 스크립트와 게시자 ID가 들어 있습니다. 별도 서비스로 운영할 때는 자신의 광고 설정으로 바꾸거나 제거하세요.
- 웹 폰트·광고 등 부가 리소스는 네트워크 연결을 사용할 수 있습니다. 외부 LLM 호출은 없습니다.
- 이 GitHub 업로드용 사본은 소스·콘텐츠·이미지·테스트를 포함합니다. 설치 패키지(`node_modules`), 재생성 가능한 빌드 결과(`dist`), 기존 Sites 프로젝트 연결 설정은 제외했습니다.
- GitHub와 기존 Sites 간 자동 동기화나 자동 배포는 설정하지 않았습니다.
- 별도 오픈소스 라이선스는 아직 지정하지 않았습니다.
